# QA Checklist

## Build
- [ ] Existing package manager used.
- [ ] Dev server starts.
- [ ] Production build succeeds.
- [ ] No uncaught console errors or broken images.

## Layout
- [ ] No horizontal overflow on mobile.
- [ ] Tablet and desktop hierarchy is consistent.
- [ ] Header/mobile menu works.
- [ ] Images retain correct aspect ratios.
- [ ] Sticky elements do not cover content.

## Functionality
- [ ] All nav links and CTAs work.
- [ ] Mobile menu is keyboard accessible.
- [ ] FAQ supports keyboard and exposes expanded state.
- [ ] Phone link is used only after number confirmation.
- [ ] WhatsApp omitted until confirmed.
- [ ] Form validates locally and says no message was sent.
- [ ] No form data sent or stored.

## Content
- [ ] No fake testimonials.
- [ ] No invented credentials, prices, warranties, timelines, or business history.
- [ ] Illustrative imagery is not presented as real work.
- [ ] Unconfirmed services are provisional/omitted.
- [ ] Rating/count not treated as permanent.
- [ ] Business facts flagged for confirmation.
- [ ] Concept clearly unofficial.

## SEO/accessibility/performance
- [ ] Unique title/meta description per page.
- [ ] Logical heading hierarchy and meaningful alt text.
- [ ] Relevant internal links.
- [ ] No keyword stuffing or fabricated structured data.
- [ ] Private concept not configured for public indexing.
- [ ] Keyboard focus and contrast checked.
- [ ] Reduced motion respected.
- [ ] Images optimized and below-fold images lazy-loaded.

## Handoff
- [ ] Report implemented files and routes.
- [ ] Report actual commands/tests and results.
- [ ] List owner-confirmation items.
- [ ] Explain local preview steps.
