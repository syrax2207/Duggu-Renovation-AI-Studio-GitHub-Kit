# Duggu Renovation & Interior — AI Studio + GitHub Kit

This is a **planning and implementation kit**, not a finished website source codebase.

## How to use
1. Extract this ZIP or upload the documents to your Google AI Studio coding project.
2. Give AI Studio `MASTER_IMPLEMENTATION_PROMPT.md`.
3. Tell it to read the PRD, facts, content, design, assets, tasks, and QA documents before coding.
4. Keep the concept private until the business owner approves it.
5. After implementation, test locally and push the generated source to a private GitHub repository.

## Important
- Business details, rating, review count, hours, services, and service area must be rechecked with the owner before launch.
- Do not use Google Maps photos or customer reviews publicly without permission.
- Do not represent placeholder/stock/AI imagery as actual Duggu projects.
- This ZIP contains project documents and instructions; AI Studio still needs to generate the website code.
