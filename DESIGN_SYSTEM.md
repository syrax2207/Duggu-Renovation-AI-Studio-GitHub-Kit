# Design System — Private Concept

## Direction
Modern Renovation Studio: contemporary, architectural, warm, trustworthy, and professional. This is a proposed concept identity, not existing business branding.

## Colors
- Warm ivory `#F5F2EC`
- Charcoal `#292A27`
- Muted bronze `#A67C52`
- Soft sage `#D9DED4`
- White `#FFFFFF`
- Muted text `#6F706A`
- Border `#E3DED5`

Use charcoal for text, ivory for major surfaces, bronze sparingly, sage for secondary surfaces. Check contrast.

## Typography
Headings: Playfair Display or similar editorial serif. Body/navigation: DM Sans or similar legible sans-serif. Limit font families and weights.

## Layout and components
- Consistent max-width container, spacious grid, clear hierarchy.
- Header: typographic wordmark, accessible navigation, one primary CTA.
- Buttons: clear labels, visible focus/hover, touch-friendly sizes.
- Service cards: image, heading, short copy, useful link.
- Gallery: responsive editorial grid, stable image ratios, no fabricated before/after.
- FAQ: accessible accordion with `aria-expanded`.
- Form: labels, local validation, no data transmission/storage.

## Photography
Use approved real images only after owner permission. Otherwise use licensed stock/illustrative assets and label them as concept imagery. Never present them as Duggu projects. No image distortion.

## Motion and accessibility
Minimal purposeful motion; respect `prefers-reduced-motion`. Semantic landmarks, visible focus, keyboard access, readable contrast, meaningful alt text, no hover-only content.

## Responsive behavior
Follow existing project conventions; test narrow mobile, typical phone, tablet, and desktop. Avoid horizontal overflow.
